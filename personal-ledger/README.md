# 個人總帳本

iPhone 記帳、Windows 管理總帳的原型。iPhone 現在可用無需 Mac 的主畫面網頁 App，帳目保存在手機；Windows 保存完整總帳。已用實際台新電子帳單驗證逐筆解析及摘要核對；匯入後先待確認。獨立程式尚未取得 Gmail 授權。

## 開始使用 Windows 版

開啟工作目錄下 `output/personal-ledger-v3/PersonalLedger.exe`，不需要額外安裝 Python。若舊版仍開啟，先完成正在編輯的資料，再關閉舊版開啟更新版。也可在此專案目錄雙擊 `Start_Ledger.cmd` 執行原始碼版（需要 Python 3.10 以上及 Tkinter）。

正式帳本預設保存在 `%LOCALAPPDATA%\PersonalLedger\ledger.sqlite3`，離線可用，不把運作中的 SQLite 資料庫放進專案的 OneDrive。選「開啟示範帳本」會使用獨立資料庫，示範紀錄不會進入正式帳本。

1. **帳本**：新增收入、支出或轉帳，修改分類／摘要，搜尋及匯出 CSV。總收入／支出不包含轉帳；這是收支統計，不代表銀行實際餘額。
2. **待確認**：比對帳本金額與來源金額，選擇保留帳本金額、採用來源、分為不同交易、關聯既有帳目或忽略非交易資料。
3. **匯入**：貼入通知或正規化 JSON、預覽 CSV 對帳單、離線解析台新信用卡 PDF。先核對摘要與逐筆金額，預覽後才匯入待確認；其他銀行 PDF 提供文字預覽。
4. **資產**：記錄股票／加密貨幣買賣與股息、查看數量／成本／報價／市值。開啟程式期間預設每 15 分鐘更新支援的行情，可在設定關閉。
5. **設定**：Gmail 唯讀授權、資料庫備份／還原、手機網址與檔案交換。原生 iPhone 開發版的網路配對另列於進階選項。Gmail 完成設定及授權後，程式開啟期間預設每 5 分鐘同步通知；離線失敗只更新狀態，不覆蓋正在編輯的資料。還原前需停止同步服務，程式會保留還原前的完整帳本備份。

同一張卡在 Apple Pay、手動記帳及 Gmail 規則中請使用相同帳戶名稱；不同卡片使用不同名稱。

## 核對行為

來源紀錄和帳目分開保存，以 `source + external_id` 防止網路重試重複入帳。同一識別碼收到不同內容會拒絕覆寫。不同來源依帳戶、商家及時間找候選；不只看金額。

- 金額與幣別一致且只有一個明確候選：關聯同一筆帳目。
- 金額／幣別不同、多個候選、日期沒有時間、來源需人工確認：保留資料並排入待確認。
- Apple Pay 與銀行商家描述不同、但同帳戶時間接近：列為疑似同筆交易，先確認再決定合併或分開。
- 同一來源在短時間重送相似交易：待確認，不自動增加第二筆支出。
- 對帳單中沒有對應帳目：先確認是否漏記、退款、手續費或轉帳。
- 信用卡月結總額、應繳、結餘與 OTP 不作為單筆消費。

金額使用最小單位整數，數量與報價使用十進位字串；例如 TWD 500.00 保存為 50000。跨幣別市值分開顯示，本版尚未自動換匯或加總成單一淨資產。

## Gmail 與銀行帳單

詳見 [Gmail／帳單／報價設定](INTEGRATIONS.md)。Gmail 需要自己的 Google Desktop OAuth 用戶端檔、銀行寄件者／專用標籤，以及使用者在 Google 頁面的唯讀授權。ChatGPT 已連接 Gmail 不會自動授權這個獨立程式。

CSV 範本位於 [examples/statement-template.csv](examples/statement-template.csv)。可設定欄位對照；需要完整年份、明確幣別、商家、金額及交易方向。[台新 PDF 對帳](TAISHIN_STATEMENT.md) 已驗證一種文字型電子帳單版型，會區分消費、費用、退款／折抵及繳款，並保留消費日與入帳日。摘要金額不符或有漏列時禁止整份匯入。其他銀行 PDF 提供文字預覽；掃描影像尚無 OCR。

其他銀行帳單及真實推播／郵件範本尚未驗證，不能保證通用解析器能讀懂所有格式。新增銀行規則時可提供去除姓名、卡號、帳號、地址的範例。

## 行情與投資範圍

- TWSE 上市股票：證交所最近可取得交易日收盤價，非盤中價。
- 加密貨幣市場填 `BINANCE`：已驗證可取得 Binance 支援交易對的最後成交價，TWD／USD 成本持倉以 USDT 報價。USDT 不視為 USD，沒有匯率時不計跨幣別損益。
- 其他加密貨幣市場使用 Coinbase 支援的交易對；該來源在目前電腦仍有 TLS 信任鏈錯誤，需另行連線驗證。
- 上櫃／美股／其他商品：本版可先使用手動報價。
- 更新失敗時保留最後快取與報價時間，程式不會自動切換報價來源。
- 成本採移動平均；股息與投資交易不會自動再寫入日常收支。轉入需填入承接成本；轉出手續費需另外記為支出，避免漏算。此版不支援放空、自動拆股、跨錢包自動承接成本或稅務報表。

## iPhone：不需要 Mac

私人入口：[隨身帳本](https://personal-ledger-pocket-yeh.yeh2003121.chatgpt.site)。在 iPhone Safari 開啟，以自己的 ChatGPT 帳號登入後選「分享 → 加入主畫面」。從主畫面圖示開啟一次，等顯示「已可離線開啟」，再測試飛航模式新增與重新開啟。Safari 與主畫面 App 請固定使用同一入口，避免帳目留在不同儲存區。

可離線新增收入／支出／轉帳、匯入 Apple Pay 捷徑 JSON、查看 Windows 總帳／待確認／持倉快取、完整備份及合併還原。金額採 BigInt 精確計算。紀錄不送到 Sites 伺服器；Sites 只提供程式檔案。

雙向交換方式詳見 [手機與 Windows 檔案交換](TRANSFER.md)：手機匯出紀錄 → Windows「匯入手機紀錄」→ 核對 → Windows「匯出手機總帳」→ 手機匯入。可透過「檔案」或 OneDrive 傳檔；未完成傳檔時兩端仍可離線記帳。這不是背景自動同步，手機網頁也不直接連到未加密的 Windows HTTP 服務。

[無 Mac 的 Apple Pay 捷徑指南](mobile-guides/APPLE_PAY_WITHOUT_MAC.md) 說明如何讓交易自動化存成檔案，再選取檔案匯入手機。Wallet 觸發、資料欄位與背景存檔仍需用自己的 iPhone 實測；網頁不能任意讀取其他 App 的推播。既有帳目的修改與確認在 Windows 完成。

網頁離線儲存可能因清除網站資料、裝置空間不足或移除 App 而消失，請定期備份。程式會請求持久儲存，但無法保證系統一定允許。

先前的 [iOS 原生開發版](ios/README.md) 保留供將來有 Mac 時使用，尚未經 Xcode 編譯或安裝。Windows 原生 App 配對服務預設關閉，與手機網頁版的檔案交換分開。

## 原始碼與驗證

核心、桌面、CSV、同步及 Gmail 使用 Python 標準函式庫。PDF 擷取另需 `python -m pip install -r requirements.txt`。重新打包需 `python -m pip install pyinstaller`，再執行 `./build_windows.ps1`。

```powershell
python -m unittest discover -s . -p 'test_*.py'
python desktop.py --smoke-test
```

測試涵蓋去重、金額差異、模糊配對、對帳單待確認、台新摘要及漏列控制、修改版本衝突、持倉成本、備份還原、Gmail 模擬授權、Windows token 保護、真實本機 HTTP 同步與桌面資料流程。手機網頁已做模擬 DOM／離線快取測試，並可用 `npm run test:browser` 在 Chromium 做端對端檢查（見 [MOBILE.md](MOBILE.md)），尚需 iPhone 實機驗證；真實 Gmail 登入及其他銀行範本需要使用者協助。

帳本變大時的行為：

- 核對只搜尋同帳戶、同類型、時間相近的帳目（使用索引），不會隨帳本筆數變慢；配對規則與結果不變。
- 匯入預覽資料、手機紀錄與區域網路同步會分批寫入資料庫。每一筆仍各自驗證、核對並回報結果，單筆被拒不影響其他筆；重新匯入相同紀錄不會重複記帳。
- Windows 介面每分鐘只檢查帳本檔案是否有變動，有變動才重新載入；重新載入後保留目前選取的列與捲動位置。搜尋在停止輸入後才篩選。
- 手機清單一次顯示 100 筆，搜尋與篩選涵蓋全部帳目。

帳本與備份檔目前未額外加密；Gmail token 使用 Windows DPAPI 保護。請將完整備份放在自己的私有儲存位置。
