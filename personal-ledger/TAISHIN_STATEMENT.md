# 台新信用卡 PDF 對帳

在 Windows 帳本的「匯入」選擇 PDF，先預覽交易及控制金額，再送入待確認。PDF 密碼只在 Windows 本機遮蔽視窗輸入，不需傳到聊天，程式不保存密碼。對帳預覽不會直接增加支出。

目前驗證的是台新信用卡電子帳單文字型 PDF：有「信用卡電子帳單」年月、帳單結帳日、繳款截止日、帳務摘要，以及「消費日／入帳起息日／消費明細／新臺幣金額／外幣折算日／消費地／幣別／外幣金額」交易表。掃描影像或其他版型會保留文字預覽，不能假設可自動解析。

解析會保留消費日及入帳日。民國年份換算西元；只有月日的資料依結帳日判斷年份，跨年時十二月歸前一年。帳單沒有時間，因此午夜只是儲存佔位，畫面應以日期顯示；不能當作凌晨實際消費。

交易分為消費、銀行費用、退款／折抵及信用卡繳款。繳款是資金移動，不重複計算支出。負項保留帳單原始負號，並以正金額的退款／折抵收入候選放入待確認；確認時須與原支出核對，不能當作薪資等一般收入。此版不會自動建立退款與原支出的關聯。

新臺幣結算金額與原幣金額分開保存。國家代碼不代表原幣幣別；帳單沒有列出的原幣資訊維持空白。國外交易服務費說明中的原消費金額不會誤當成本筆服務費金額。

程式檢查下列控制金額：

- 上期應繳減去已繳退款，應等於前期餘額。
- 前期餘額加上本期新增，應等於本期累計應繳。
- 逐筆消費與費用減去退款／折抵，應等於本期新增。
- 逐筆繳款應與帳務摘要的已繳退款總額一致。
- 交易表應沒有未辨識列。

任一控制不一致，代表尚未完整核對，須先檢查漏列、其他調整或不同版型。帳單應繳、最低應繳、信用額度、點數、廣告及付款提醒不作為消費。溢繳等負餘額摘要、繳款沖回、零元列與無法解析列會要求人工確認。

交易識別碼依帳單月份、結帳日、帳戶、信用卡區段及正規化交易資料建立，不依解密後 PDF 檔案的隨機差異建立。重複匯入相同帳單不重複新增來源；同日同商家同金額的兩筆真實交易仍保留為兩筆。不同卡片在帳單中有獨立區段，但匯入帳戶名稱仍由使用者選擇；要分開管理各張卡片時應分別核對帳戶歸屬。

獨立本機預讀工具 `prepare_statement.py` 只在 `%LOCALAPPDATA%\PersonalLedger\imports\<隨機作業編號>` 保存解密副本及擷取文字，方便核對版型，尚不匯入總帳。這些副本包含個人財務資料，使用完可在該資料夾自行移除；原始附件不會改寫。一般 App 讀取 PDF 只需記憶體解密，不會自動建立這些預讀副本。
